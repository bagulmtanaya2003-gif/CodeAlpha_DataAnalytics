# Task 2 – Exploratory Data Analysis (EDA)

Part of the **CodeAlpha Data Analytics Internship**.

## Objective
To explore the book dataset, identify patterns and trends, test relationships, and detect data-quality issues.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Analysis Performed
- Explored data structure and data types
- Checked missing and duplicate values
- Cleaned Price and Rating columns
- Performed statistical analysis
- Analyzed price and rating distributions
- Tested the relationship between price and rating
- Detected price outliers using IQR

## Visualizations
- Price Distribution
- Rating Distribution
- Price Boxplot
- Price vs Rating
- Average Price by Rating

## Key Finding
Book price and rating showed a **very weak relationship**, with correlation ≈ **0.028**.

EDA • Data Cleaning • Statistics • Data Visualization • Hypothesis Testing
