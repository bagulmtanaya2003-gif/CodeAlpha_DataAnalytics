# CodeAlpha Data Analytics Internship

## Task 1 – Web Scraping

This project is completed as part of my **CodeAlpha Data Analytics Internship**.

### 📌 Objective

To collect and extract useful data from a website using Python web scraping techniques and store it in a structured format.

### 🛠️ Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas

### 📂 Project Structure

```text
Task-1-Web-Scraping/
│
├── scraper.py
├── data/
├── requirements.txt
└── README.md
```

### 🔎 What I Did

* Sent requests to the target website
* Extracted data from HTML
* Parsed the webpage using BeautifulSoup
* Organized the data using Pandas
* Saved the scraped data for further analysis

### 📊 Output

The scraped dataset is stored in the `data` folder.
